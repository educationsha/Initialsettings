# UAV development

Recommended progression:

1. Build and test perception models offline.
2. Use PX4 SITL/Gazebo simulation.
3. Add MAVLink/MAVSDK telemetry in simulation.
4. Test multi-agent coordination in simulation.
5. Connect to permitted real hardware only after appropriate simulation and safety validation.

This repository is for development, research, and simulation. It does not provide autonomous weapon targeting, engagement logic, or harmful payload control.
